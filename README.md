# Mitchell-Tech-V120.2-A-self-teaching-scientific-and-graphing-calculator-
Mitchell Tech V120.2  A self-teaching scientific and graphing calculator in a single HTML file. Start with ordinary arithmetic, learn what each control does, and work up to functions, graphs and introductory calculus. A local page ledger remembers notes and recalls the source, inspired by the closed-page approach in MPLPB.
